# Семинар "Указатели и память"

## [Презентация](./slides.pdf)

## Содержание

### [`memcpy`](./1_memcpy)
Указатель на данные. Арифметика, доступ.
**Копирование памяти через `char` и `int`, замер скорости.**

### [`transform`](./2_transform)
Указатель на функцию. Callback. begin+end.
**Настраиваемое преобразование данных.**

### [`sort`](./3_sort)
Функции, работающие с любым типом данных (`void*` + `sizeof`).
**Сортировка по произвольному порядку.**

### [`dispatch`](./4_dispatch)
**Структуризация консольных команд.**
